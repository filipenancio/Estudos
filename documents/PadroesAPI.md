# API

A API e uma interface de comunicacao, que fornece acesso a um servico. Um exemplo e a API Web dos correios, que fornece informacoes de endereco.

Dos padroes mais comuns: - RPC, Soap e REST

RPC - Padrao mais antigo
Soap - Utiliza uma definicao em XML para uso do RPC
REST - GET, POST, PUT, DELETE
